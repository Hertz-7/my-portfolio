## Problem

QLU.ai needed to build a full-stack AI-native product for executive sourcing — one that could handle natural-language candidate search over millions of profiles, automate outreach at scale, and integrate high-volume voice calling — while supporting 1,500+ users and 100+ concurrent sessions.

## Approach

Led the engineering for a business unit of three products — the Dialer, Outreach automation, and AI Voice SDR — managing a team of 3 developers and 2 QA engineers across architecture, delivery, code quality, and release process. Directed the architecture for all three platforms from the ground up, establishing the shared infrastructure and patterns that let the team ship independently without accumulating integration debt.

## What I Built

### AI People Search

The core revenue product: natural-language candidate search over millions of executive profiles. Translates freeform queries into optimized SQL and Elasticsearch queries. Query optimization work delivered up to **90% performance improvement** on complex searches, reducing median search latency from seconds to sub-second.

### Outreach Automation

An event-driven system with complex scheduling logic: campaigns can target candidates based on availability windows, seniority level, industry, and past engagement history. Redis-backed background jobs handle campaign execution, with pub/sub fan-out delivering real-time status updates to the dashboard as each outreach touch executes.

### Twilio Dialer

High-volume outbound calling infrastructure handling call reliability, call-state management, status webhooks, and real-time call events over WebSockets. Built on Twilio's Voice API with a custom call队列 that manages connection pooling and automatic failover across Twilio accounts.

The AI Voice SDR was built directly on the Dialer for autonomous outbound recruitment calls — handling speech recognition, response generation, and call disposition logging without human intervention.

### Billing & Infrastructure

Refactored the credit and subscription billing system end-to-end, handling migrations across PostgreSQL, MySQL, and MS SQL Server in a zero-downtime deployment pattern. Built a reusable authentication microservice and an admin operations panel for internal tooling.

## Stack

React · NestJS · Elasticsearch · Redis · Twilio · WebSockets · PostgreSQL · MySQL · MS SQL Server · Redis Pub/Sub

## Impact

Scaled to 1,500+ users and 100+ concurrent sessions. The AI People Search query optimization work delivered up to 90% latency reduction on complex searches. The Dialer handles thousands of concurrent outbound calls per day.
