## Problem

Thy Reality wanted a platform where users could buy and trade fractions of property using cryptocurrency — and a mobile app to match. The challenge was the trading workflow: secure custody, atomic execution, and real-time pricing across a fragmented property portfolio.

## Approach

Built the web platform end-to-end and shipped the companion mobile app alongside it. Designed GraphQL APIs from the start so the mobile and web clients shared the same data layer without parallel REST surfaces to maintain.

## What I Built

### Web Platform

A NestJS backend with secure purchase and trading workflows against a custodial wallet integration, and a React + TypeScript + Tailwind frontend that walks users through portfolio discovery, purchase, and trade execution.

### Mobile App

The companion mobile app in React Native, against optimised GraphQL APIs. The GraphQL schema was designed around the trading workflow specifically — avoiding over-fetching on the listing and detail screens — and the resolvers cached aggressively to keep mobile data costs low.

## Stack

NestJS · React · React Native · TypeScript · GraphQL · Tailwind CSS

## Impact

Shipped a property-fractionalisation platform with both web and mobile clients, on a shared GraphQL data layer that the mobile team could iterate against without backend changes for every UI tweak.
