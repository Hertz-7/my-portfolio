## Problem

Property investment is gated behind whole-asset purchases, illiquid transactions, and paperwork-heavy onboarding. PropNerd set out to make fractional property investment as frictionless as buying a token: discovery, custody, trade execution, and a mobile-first UX — with the property assets tokenized on-chain.

## Approach

Built the platform end-to-end across web and mobile, with Solana as the settlement layer for fractional shares. AI-assisted tooling sits on top of the listing and discovery flows to surface properties that match a buyer's profile.

## What I Built

### Web Platform

A Next.js application with secure purchase and trading workflows against an on-chain tokenization integration. The frontend walks users through portfolio discovery, KYC, custody setup, purchase, and trade execution — with AI-assisted recommendations layered onto the listing surface.

### Solana Tokenization Layer

A backend service that handles the property-asset tokenization flow on Solana: minting fractional share tokens per property, managing the on-chain custody leg of every trade, and reconciling on-chain state with the off-chain listing data.

### Mobile App

The companion mobile app in React Native, sharing the same data layer as the web client. Mobile-first flows for browsing properties, tracking holdings, and executing trades from a phone.

### AI-Assisted Discovery

AI tooling that helps buyers find properties matching their risk profile, geography, and budget — surfacing listings that fit a buyer's stated preferences rather than only keyword matches.

## Stack

Next.js · React Native · Solana · TypeScript · AI

## Impact

Shipped a fractional property investment platform with web and mobile clients, on-chain tokenization on Solana, and AI-assisted discovery — turning whole-asset property investment into a token-purchase UX.
